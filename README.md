# AI데이터융합학과 상담 시스템

학과 상담을 1:1 실시간 채팅으로 주고받을 수 있는 웹 서비스입니다.

🔗 **[상담 시스템 바로가기](https://aidata-qna.hufs.ac.kr/)**

---

## 이용 방법

1. 위 링크에 접속합니다.
2. **HUFS 계정(@hufs.ac.kr)으로 로그인**합니다.
3. 질문을 입력하면 관리자에게 전달됩니다.
4. 관리자가 답변하면 채팅창에 표시됩니다.

> 한국외국어대학교 구성원이면 누구나 이용할 수 있습니다.
> 이중전공·부전공 학생도 학과 소속과 관계없이 질문할 수 있습니다.

### HUFS 계정이 없다면

HUFS 메일은 직접 가입해야 합니다. [mail.hufs.ac.kr](https://mail.hufs.ac.kr) 에서
최초 1회 계정을 만든 뒤 다시 로그인해 주세요.

---

## 주요 기능

- HUFS Google 계정 로그인 (본인 확인)
- 관리자와 1:1 실시간 채팅
- 상담 내역은 본인과 관리자만 열람 가능
- 계정 기준이라 다른 기기에서 접속해도 대화가 이어짐

---

## 개인정보 안내

- 로그인 시 학교 계정의 **이름과 이메일 주소**가 상담 스레드에 저장됩니다.
- 상담 내용은 **본인과 관리자만** 열람할 수 있습니다. 다른 학생은 볼 수 없습니다.
- 비밀번호는 이 서비스가 다루지 않습니다. 로그인은 Google 이 처리합니다.
- 상담 내역은 관리자가 주기적으로 삭제합니다. 자동 삭제는 이루어지지 않습니다.
- 본 서비스는 학과 내부 용도로만 운영됩니다.
