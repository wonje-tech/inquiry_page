# AI데이터융합학과 상담 시스템

학과 재학생과 관리자(교수·조교)가 1:1로 실시간 상담을 주고받을 수 있는 웹 서비스입니다.

🔗 **[상담 시스템 바로가기](https://aidata-qna.hufs.ac.kr/)**

---

## 이용 방법

### 학생

1. 위 링크에 접속합니다.
2. **학번**과 **이름**을 입력하고 로그인합니다.
3. 질문을 입력하면 관리자에게 전달됩니다.
4. 관리자가 답변하면 채팅창에 표시됩니다.

> 재학생 명단에 등록된 학번·이름만 로그인이 가능합니다.
> 로그인이 되지 않는 경우 학과 사무실로 문의하세요.

---

## 주요 기능

- 학번·이름 기반 재학생 확인 (원본 명단은 서버에 저장되지 않음)
- 관리자와 학생 간 실시간 1:1 채팅
- 상담 내역은 본인과 관리자만 볼 수 있음

---

## 개인정보 안내

- 로그인 시 입력한 학번·이름은 상담 스레드 표시 용도로만 사용됩니다.
- 상담 내용은 **본인과 관리자만** 열람할 수 있습니다. 다른 학생은 볼 수 없습니다.
- 상담 내역은 **접속한 브라우저 기준**으로 유지됩니다.
  다른 기기나 다른 브라우저, 시크릿 창에서 접속하면 새 상담이 시작됩니다.
- 상담 내역은 관리자가 주기적으로 삭제합니다. 자동 삭제는 이루어지지 않습니다.
- 본 서비스는 학과 내부 용도로만 운영됩니다.
